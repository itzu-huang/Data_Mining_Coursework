# Titanic Clustering

## Objective

Explore Titanic passenger clusters and summarize their profiles.

## Dataset

The Titanic subset referenced by the source exercise; raw passenger data is not included.

## Methods

Missing-value handling, One-Hot Encoding, StandardScaler, K-Means, SSE/Elbow, Silhouette, cluster-to-class majority mapping, and an aggregate cluster profile.

## What I Practiced

Compare clustering with and without the target for different exercise questions, then describe clusters using feature summaries.

## Key Observation

Cluster naming and majority mapping are descriptive interpretations of this dataset, not causal findings.

## Files

- `titanic-kmeans.py`
- `titanic_cluster_profile.csv` (four-row aggregate summary; no raw passenger rows)
