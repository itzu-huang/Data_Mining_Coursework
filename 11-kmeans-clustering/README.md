# K-Means Clustering

## Objective

Explore two distinct clustering exercises: Bank customer grouping and Titanic passenger profiles.

## Dataset

Bank and Titanic datasets referenced by the exercises; raw datasets are not included.

## Methods

K-Means, SSE/Elbow, Silhouette, centroid inspection, and cluster profiling. Titanic also includes a cluster-to-class majority mapping exercise.

## What I Practiced

Compare cluster structure and describe cluster profiles separately from any supervised prediction exercise.

## Key Observation

K-Means was more useful for exploring cluster structure than as the primary classification method. Cluster profiles describe this dataset and do not imply causal relationships.
