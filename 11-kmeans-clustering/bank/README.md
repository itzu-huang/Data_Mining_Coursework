# Bank Clustering

## Objective

Explore Bank customer segments without using the target as an input feature.

## Dataset

The 600-row Bank clustering dataset referenced by the source exercise; it is not included.

## Methods

Categorical encoding, scaling, K-Means, SSE across candidate K values, Elbow inspection, centroids, Silhouette, and a separate comparison with the known target.

## What I Practiced

Read cluster summaries and distinguish unsupervised grouping from a class-prediction task.

## Key Observation

The cluster-to-target comparison is an exploratory mapping, not evidence that clusters cause customer outcomes.
