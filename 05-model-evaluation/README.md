# Model Evaluation

## Objective

Evaluate classification errors in a Bank customer exercise where error types have different costs.

## Dataset

Bank customer data referenced by the exercise; the CSV is not included.

## Methods

Confusion Matrix, Accuracy, Precision, Recall, F1, and a Cost Matrix.

## What I Practiced

Relate false-positive/false-negative counts to class-specific metrics and application costs.

## Key Observation

This exercise focuses on understanding evaluation metrics and misclassification costs. Because the preserved coursework calculation is not based on an independent held-out test estimate, the reported values should not be interpreted as unbiased generalization performance.
