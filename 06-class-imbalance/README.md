# Class Imbalance

## Objective

Compare common resampling approaches on an imbalanced Titanic survival target.

## Dataset

Titanic training data referenced by the exercise; the dataset is not included.

## Methods

Random under-sampling, random over-sampling, and SMOTE, with categorical encoding and missing-value handling in the exercise workflow.

## What I Practiced

Under-sampling reduces majority-class rows; over-sampling duplicates minority-class rows; SMOTE synthesizes minority-class examples.

## Key Observation

> This coursework artifact demonstrates under-sampling, over-sampling, and SMOTE concepts. The preserved exercise still includes a categorical Ticket field in the SMOTE input, so additional preprocessing would be required before running it as a complete reusable pipeline.
